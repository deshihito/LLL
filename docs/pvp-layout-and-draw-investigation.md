# 対人戦画面・ドロー仕様の調査結果

## 発見した原因

### PCで縦長になっていた原因

- 対人戦のミニマル画面に `max-width: 980px` が設定されていた。
- 敵の場、プレイゾーン、自分の場、手札を通常フローで縦に積んでいた。
- 戦闘画面だけ16:9フレームの `aspect-ratio` が設定されていなかった。

そのため、PCの横幅を活かせず、カード領域が縦方向へ伸びていた。

### アクションを起こせなかった原因

- 対人戦の最小UIに「ターン終了」操作が存在しなかった。
- 相手ターン中と自分のターン中の状態表示が弱く、操作可能状態を判別しにくかった。
- 盤面カードの操作と手札操作が同じ画面にありながら、アクションを行う導線がカード詳細に限定されていた。

今回、ターン状態をヘッダーへ常設し、自分のターンだけ有効な「ターン終了」ボタンを追加した。

## 共通ドロー仕様

- バトル開始時：手札4枚
- ターン開始時：アクティブプレイヤーが1枚ドロー
- 山札が空の場合：ドローせず手札枚数を維持
- 対人戦：Supabaseのバトル作成・ターン処理へ適用
- 試し切り：共通バトルエンジンの `createBattle`・ターン処理へ適用

## レイアウト方針

対人戦は画面を複数のレイヤーへ分割せず、PCでは一つの16:9バトルフレームへ以下を収める。

- ヘッダー
- 敵カードと自分のカード
- 手札
- ターン操作
- ログ導線

プレイゾーンは通常時に独立したパネルとして目立たせず、カードのフリック中だけドロップ領域として反応する。スマートフォンでは画面幅に応じて縦方向へ自然に戻す。
